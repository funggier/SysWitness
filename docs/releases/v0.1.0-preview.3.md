# SysWitness v0.1.0-preview.3 — Windows x64 Portable

SysWitness now exposes a bounded Process Tree API from retained Sysmon creation evidence. It expands descendants from a selected process, shows source-reported parent references, and preserves the child creation event behind every relationship.

## Process Tree API

```http
GET /api/v1/processes/{processGuid}/tree?computer={recordedComputer}&depth=3&limit=100
X-SysWitness-Token: <private-client-token>
```

Requires `processes.read`. The computer name must match retained Sysmon evidence exactly. No new client scope or permission expansion is introduced.

- Nodes distinguish creation evidence in this view from reference-only identities.
- Relationships carry `basis=sourceReported` and original child creation evidence; the assembled graph is `quality=derived`.
- Missing/ambiguous GUIDs and self references are unresolved evidence. Conflicting parents and cycles are flagged instead of silently selecting a result.
- Depth is 0..8 and the node limit is 1..256. A fixed budget of 1000 unique source events (plus lookahead) bounds evidence considered. Depth/node/evidence limit flags describe partial expansion.
- Expansion queries share one SQLite read snapshot. No evidence, bookmark or Windows setting is changed; no database migration is required.

See the [Tree guide](https://github.com/funggier/SysWitness/blob/v0.1.0-preview.3/docs/PROCESS_TREE_TH.md) for exact semantics, inputs and limits.

## Remaining limits

- Tree source verification uses synthetic Sysmon fixtures. The development account has no readable Sysmon channel; live Sysmon parent/child validation remains open.
- This is a bounded descendant view with other parents represented as references, not a complete ancestor search or live inventory of every process. Unknown identity returns a requested reference-only root.
- Exact source GUID matching and reported parent fields are not independent proof of execution causality. PID-only Security/WMI/snapshot sources are not inferred into this tree.
- Collection gaps, retention, missing fields and graph limits can leave history incomplete. Limits bound graph data, not SQL scan duration; large-history query measurements/indexing remain future work.
- Portable relocation was verified on the same Windows computer, not all volumes, filesystems or machines.
- Observation-only localhost read API; no prevention, process control, quarantine, shell or Windows configuration endpoint.
